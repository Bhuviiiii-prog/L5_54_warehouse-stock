# Issues Found in `warehouse_stock_manager.py`

Line numbers refer to the **original** file. Sources: Bandit report, program output, and manual review (Pylint and Flake8 codes are the ones I expect them to report). Ordered by severity, high and medium first.

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| 1. Weak MD5 hash | Security (Bandit B324, High; CWE-327) | 31 | `hashlib.md5(...)` is flagged as a weak hash. Here it only makes a short fingerprint for printed bin labels, not a security control, but the call does not say so. | Pass `usedforsecurity=False` to document the intent, or switch to `sha256`. Changing the algorithm changes the checksums, so existing printed labels would no longer match. |
| 2. `eval` on supervisor formula | Security (Bandit B307, Medium; CWE-78) | 62 | `eval(formula, {"current": current})` runs whatever the console user types. Restricting the globals dict does not make `eval` safe, so this allows arbitrary code execution. | Replace with a small `ast`-based evaluator that allows only numbers, the name `current`, and `+ - * / //`. Reject anything else with `ValueError`. |
| 3. Needless `eval` in `main` | Security (Bandit B307, Medium) | 80 | `eval("print('stock audit complete')")` is a constant string, so `eval` adds risk and no value. | Call `print("stock audit complete")` directly. |
| 4. Overselling silently deletes stock, errors swallowed | Bug / Error handling (Bandit B110, Low; Pylint W0702 bare-except) | 18-24, 72-73 | Bare `except: pass` hides every error. `removeStock("GHOST-9", 1)` fails silently. `removeStock("WID-001", 500)` pushes stock negative, then deletes WID-001 entirely, losing 28 real units without any message. | Check that the SKU exists and that `qty` does not exceed stock. Raise `KeyError` or `ValueError` with a clear message, and catch them in `main()` to print them. |
| 5. No input validation | Bug / Logic | 12-16, 69-70 | `addStock("WID-002", -4)` stores negative stock, which shows up in the demo as `WID-002 stock: -4`. `addStock(404, 15)` accepts an int SKU, which comes back as the string `"404"` after the JSON save/load round trip. | Require `sku` to be a non-empty string and `qty` to be a positive integer, raising `ValueError` otherwise. |
| 6. Hardcoded supervisor password | Security (Bandit B105, Low; CWE-259) | 10, 59, 76 | The password is a plain string in the source and is repeated in `main()`. Anyone with the code has the credential, and `!=` is not a constant-time comparison. | Read it from an environment variable (e.g. `WH_SUPERVISOR_PASSWORD`), compare with `hmac.compare_digest`, and remove the literal from `main()`. |
| 7. Wrong password fails silently | Bug / Error handling | 59-60 | `applyAdjustment` just `return`s on a bad password, so the caller cannot tell the adjustment did not happen. | Raise `PermissionError("Invalid supervisor password")`. |
| 8. Mutable default argument | Code quality (Pylint W0102) | 12 | `history=[]` is created once and shared across all calls, so history leaks between calls. It is also never returned or saved, so it is effectively dead. | Use `history=None` and create a new list inside the function when it is `None`. |
| 9. Unsafe file handling | Code quality / Reliability (Pylint R1732, W1514) | 33-42, 63-65 | Files are opened without `with`, so they stay open if an exception occurs, and no encoding is given. `loadStock` also uses `f.read()` plus `json.loads`. | Use `with open(..., encoding="utf-8")` and `json.load` / `json.dump`. |
| 10. `getStock` raises raw `KeyError` | Bug / Robustness | 26-27 | Asking for an unknown SKU crashes with an unhelpful `KeyError`. | Return `warehouse_stock.get(sku, 0)`, or raise a clear custom error, and document which. |
| 11. Unused imports and variable | Code quality (Pylint W0611, W0612; Flake8 F401, F841, W291) | 2, 4, 54 | `logging` and `os` are never used. `total_units` in `checkReorder` is computed and never used, and its line has trailing whitespace. | Delete the two imports and the `total_units` line. |
| 12. Global state and `global` statement | Design (Pylint W0603) | 8, 35 | `global warehouse_stock` and reassigning the dict make the module hard to test. | Mutate in place with `warehouse_stock.clear()` and `.update(...)`. Longer term, pass the stock dict or use a class. |
| 13. Naming, docstrings, style | Style (Pylint C0103, C0116, C0114; Flake8 N802 if enabled) | 12-79 (all function definitions) | Functions use camelCase (`addStock`, `skuChecksum`) instead of snake_case. No module or function docstrings. `%` string formatting is used. | Rename to snake_case, add docstrings, and use f-strings. |
| 14. Code runs on import | Design (Pylint C0103 on module scope) | 82 | `main()` is called at module level, so importing the file runs the demo and writes files. | Guard it with `if __name__ == "__main__":`. |
